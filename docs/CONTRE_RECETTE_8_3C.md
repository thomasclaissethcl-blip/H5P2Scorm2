# Contre-recette ciblée du lot 8.3c : YouTube

Cette recette distingue volontairement l'exécution du lecteur H5P et l'autorisation de lecture par YouTube.

- [ ] 1. Le H5P source `3385280591.h5p` peut être importé dans le convertisseur.
- [ ] 2. Un HTML monofichier de ce H5P peut être téléchargé.
- [ ] 3. Ouvert directement sur le disque, le HTML affiche l'activité et l'avertissement `file://` (YouTube peut rester bloqué).
- [ ] 4. Après publication du même fichier en HTTPS, la vidéo est jouable **dans H5P**. Si elle reste bloquée, noter précisément le code d'erreur et l'environnement.
- [ ] 5. L'export d'un H5P Video avec MP4 local fonctionne toujours sans réseau.
- [ ] 6. Une Game Map exportée en monofichier présente toujours les images Memory.
- [ ] 7. Les exports SCORM et HTML multifichier restent fonctionnels.

Les contrôles 1, 2, 3, 5, 6 et 7 peuvent être réussis même si le contrôle 4 échoue. Le contrôle 4 ne doit pas être déclaré réussi si le bouton renvoie vers YouTube hors du H5P.
