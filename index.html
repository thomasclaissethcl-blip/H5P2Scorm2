    Compatibilité, limites et détails techniques
    

    

    

    Compatibilité et limites 
    

    

    

      

    • Trois formats disponibles : SCORM 1.2 avec suivi LMS, HTML multifichier autonome et HTML monofichier interactif (compatibilité expérimentale selon le contenu).
      • 

    • Runtime figé : H5P Standalone 3.8.2, plafond de compatibilité déclaré H5P Core API 1.28. Une bibliothèque requérant une API plus récente bloque la génération.
      • 

    • Score SCORM normalisé de 0 à 100, quel que soit le barème natif du H5P.
      • 

    • Reprise stricte limitée à 4000 caractères après optimisation. Le mode Moodle 64K est expérimental.
      • 

    • Les messages ordinaires de sauvegarde ne sont jamais affichés dans l'activité. Seules les alertes utiles peuvent apparaître.
      • 

    • Certains types H5P peuvent restaurer leur progression sans restaurer tous les détails visuels.
      • 

    • Le contenu H5P et le CSS sont traités localement. Le lecteur H5P est récupéré au moment de la génération puis embarqué dans les deux formats. Aucun CDN n’est nécessaire à la lecture du mini-site HTML.
